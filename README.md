## Overview

Arturia Mini V recreates the iconic Minimoog Model D, the monophonic synthesizer that defined the sound of bass and lead synthesis and remains the template for countless analog instruments.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Mini V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Three OSCs** | Three oscillators with waveform mix and coarse/fine tune per voice |
| **Ladder Filter** | Moog transistor ladder filter with self-oscillation and key tracking |
| **Mod Wheel** | Vibrato and filter modulation depth controlled by the mod wheel |
| **Polyphony Extension** | Poly mode added beyond the original monophonic hardware |
